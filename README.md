# Portfolio - Stephane WU

## Présentation du projet

Mon portfolio regroupant mon parcours, mes compétences et mes projets, disponible à l'adresse suivante : [portfolio-stephanewu.netlify.app](https://portfolio-stephanewu.netlify.app/)

## Technologies

React 19, Vite, React Router, CSS

## Fonctionnalités

- Sections : À propos de moi, Compétences, Projets, Parcours
- Version française et anglaise
- Thème clair / sombre

## Organisation du code

- `src/component/` : les composants
- `src/css/` : le style de chaque composant
- `src/data/` : les textes et les traductions

## Lancer le projet en local

```bash
git clone https://github.com/kuchiro/portfolio-react.git
cd portfolio-react
npm install
npm run dev
```
